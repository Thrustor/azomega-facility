# azomega-facility

Marketing site for **AZΩ Facility** — facility maintenance in Riga.

English is the primary language; a Latvian toggle is available.

Contact: [hello@azomega.lv](mailto:hello@azomega.lv)

## Setup

```bash
npm install
```

## Development

```bash
npm run dev
```

## Production build

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

## Hosting

The static `dist/` output can be hosted on Vercel, GitHub Pages, Netlify, or any static host.
